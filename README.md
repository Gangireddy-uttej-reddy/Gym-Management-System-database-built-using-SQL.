# Gym Management System database built using SQL
This project demonstrates a Gym Management System database built using SQL. It covers database creation, table design, constraints, and advanced SQL queries including clauses, operators, and window functions.
# 🏋️ Gym Management SQL Project

## 📌 Overview

This project is a simple **Gym Management Database** using SQL.
It stores member details, attendance, and payment information.

---

## 🗂️ Table

**gym_members**

* member_id (Primary Key)
* member_name
* age, gender, city
* plan_type
* fee, payment_status
* trainer_name

---

## 🔍 Concepts Used

* SELECT, WHERE, ORDER BY
* GROUP BY, HAVING
* LIKE, IN, BETWEEN
* Window Functions (ROW_NUMBER, RANK)

---

## 🚀 How to Run

1. Create database
2. Run SQL file
3. Execute queries
